# AI Chef

AI Chef is a full-stack recipe and nutrition web application designed to help users discover, create, and manage meals in one place. The app combines recipe browsing, AI-powered recipe generation, meal planning, nutrition tracking, and community features into a single platform.

## Project description

This project is a cooking-focused application where users can:

- Create accounts and log in securely
- Browse and save favorite recipes
- Generate custom recipes using AI based on ingredients or prompts
- Plan weekly meals and create shopping lists
- Track nutrition goals and cooking history
- Follow community feed and recipe collections
- Access an admin dashboard for managing users, recipes, and comments

## Tech stack

- Frontend: React, Vite, Tailwind-inspired styling
- Backend: Node.js, Express
- Database: MongoDB
- Authentication: JWT and bcrypt
- AI integration: Google Gemini API
- Real-time features: Socket.IO

## Main purpose

The goal of the project is to make meal planning and cooking easier, smarter, and more personalized by merging recipe management with AI assistance and health-focused tracking.

## Run the project

Backend:

npm run dev

Frontend:

npm run dev

Then open the app in the browser and use the frontend local URL displayed by Vite.

## Key feature areas

- AI recipe generation
- User authentication and profile management
- Meal planner and shopping list
- Nutrition dashboard
- Recipe collections and social feed
- Admin control panel
